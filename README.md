# Spelling Practice Page

This repository contains a single static page, `spelling_practice.html`, that helps a child practice a curated list of spelling words through suggested activities.

## Previewing the Page Locally

You can open the HTML file directly in any modern browser. The instructions below cover a few common options, including Safari.

### macOS (Safari)
1. Download or clone this repository to your Mac.
2. Open Finder and navigate to the folder that contains `spelling_practice.html`.
3. Right-click the file, choose **Open With**, and select **Safari**.
   * Alternatively, open Safari, press <kbd>⌘</kbd> + <kbd>O</kbd>, and browse to the file.
4. The page will load locally and is ready for review or printing.

### Windows (Edge or Chrome)
1. Open File Explorer and locate `spelling_practice.html`.
2. Double-click the file to launch it in your default browser, or right-click and select **Open with** to choose another browser.

### Serving Over `http://localhost`
If you prefer to run a lightweight local server (useful when testing from a phone or tablet on the same network), you can use Python:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000/spelling_practice.html> from your browser—or <http://your-computer-ip:8000/spelling_practice.html> from another device on the same Wi-Fi network.

## Printing Tips
- Use the browser's print dialog (<kbd>⌘</kbd> + <kbd>P</kbd> on macOS or <kbd>Ctrl</kbd> + <kbd>P</kbd> on Windows) to print the page.
- Selecting **Background Graphics** (or similar) ensures the soft colors appear on the printout.
